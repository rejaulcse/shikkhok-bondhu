শিক্ষক সেবা — PWA (হোম স্ক্রিন অ্যাপ)
================================================

এই ফোল্ডারে যা আছে
--------------------
- index.html, style.css, app.js  → অ্যাপের মূল কোড (এগুলোতে হাত দেয়ার দরকার নেই)
- config.js                       → শুধু এই ফাইলটাই এডিট করবেন (টাইটেল, বাটন, লিংক, সাব-মেনু)
- manifest.json                   → অ্যাপের নাম/আইকন সেটিংস (থিম কালার এখানেও বদলাতে পারবেন)
- icon-192.png, icon-512.png, icon-180.png → অ্যাপ আইকন (চাইলে নিজের আইকন দিয়ে বদলে দিতে পারবেন, একই নামে রাখতে হবে)
- images/hero.jpg                 → উপরের ব্যাকগ্রাউন্ড ছবি (নিজের ছবি দিয়ে বদলে দিন, একই নাম রাখুন)
- service-worker.js               → অফলাইনেও অ্যাপ খুলবে, এতে হাত দেয়ার দরকার নেই


ধাপ ১: নিজের মতো কাস্টমাইজ করুন
--------------------------------
config.js ফাইলটি যেকোনো টেক্সট এডিটরে (নোটপ্যাড/VS Code) ওপেন করুন।
এখানে বদলাতে পারবেন:
  - appTitle        → অ্যাপের নাম
  - heroImage        → উপরের ছবি (images ফোল্ডারে আপনার ছবি রেখে নাম মিলিয়ে দিন)
  - menu             → বাটনগুলো — প্রতিটার title ও url বসিয়ে দিন
                        সাব-মেনু চাইলে url এর বদলে children: [ ... ] ব্যবহার করুন
  - designerName / designerRole / designerInstitute → নিচের ক্রেডিট লাইন

উদাহরণ ইতিমধ্যে config.js এ দেয়া আছে, সেটা দেখে বুঝে নিজের লিংক বসিয়ে দিন।
প্রতিটা পরিবর্তনের পর ফাইলটি সেভ করলেই হবে।


ধাপ ২: ইন্টারনেটে হোস্ট করুন (ফ্রি, GitHub Pages দিয়ে)
--------------------------------------------------------
PWA হোম স্ক্রিনে বসাতে হলে এটাকে আগে একটা https লিংকে হোস্ট করতে হবে।
সবচেয়ে সহজ ফ্রি উপায় — GitHub Pages:

  ১. github.com এ একটা ফ্রি অ্যাকাউন্ট খুলুন (না থাকলে)
  ২. একটা নতুন Repository তৈরি করুন, নাম দিন যেমন: shikkhok-bondhu
  ৩. এই ফোল্ডারের সবগুলো ফাইল (ও images ফোল্ডার সহ) সেই Repository তে আপলোড করুন
     (GitHub এর ওয়েবসাইট থেকেই "Add file → Upload files" দিয়ে টেনে ছেড়ে দেয়া যায়)
  ৪. Repository এর Settings → Pages এ যান
  ৫. Branch: main, Folder: / (root) সিলেক্ট করে Save করুন
  ৬. ১-২ মিনিট পর একটা লিংক পাবেন, যেমন:
     https://আপনার-ইউজারনেম.github.io/shikkhok-bondhu/

(বিকল্প: Netlify.com বা Vercel.com এও ফোল্ডার টেনে ছেড়ে দিয়ে ফ্রি হোস্ট করা যায়,
 GitHub এর চেয়েও সহজ — drag & drop করলেই লিংক পাওয়া যায়।)


ধাপ ৩: মোবাইলে হোম স্ক্রিনে ইনস্টল করুন
-------------------------------------------
  ১. মোবাইলে Chrome ব্রাউজার দিয়ে আপনার হোস্ট করা লিংকটি খুলুন
  ২. ওপরে ডানদিকে মেনু (⋮) চাপুন → "Add to Home screen" / "Install app" এ ট্যাপ করুন
     (অনেক সময় Chrome নিজে থেকেই নিচে একটা "Install" ব্যানার দেখাবে)
  ৩. নাম কনফার্ম করে "Add"/"Install" চাপুন
  ৪. এখন হোম স্ক্রিনে ও অ্যাপ ড্রয়ারে অন্য অ্যাপগুলোর মতোই আইকন দেখা যাবে
  ৫. আইকনে ট্যাপ করলে ফুল স্ক্রিনে খুলবে, ব্রাউজারের বার দেখা যাবে না


নতুন করে আপডেট দিতে চাইলে
---------------------------
config.js বা অন্য কোনো ফাইল বদলে আবার হোস্টিং সাইটে আপলোড করলেই
পরের বার অ্যাপ খুললে (ইন্টারনেট কানেকশন থাকা অবস্থায়) নতুন তথ্য দেখাবে।


সমস্যা হলে
-----------
- আইকন/ছবি না দেখালে: ফাইলের নাম ঠিক আছে কিনা (ছোট হাতের/বড় হাতের অক্ষর মিলিয়ে) চেক করুন
- বাটনে ক্লিক করে লিংক না খুললে: config.js এ url এর আগে https:// আছে কিনা দেখুন
- "Add to Home screen" অপশন না দেখালে: প্রথমে সাইটটি https লিংকে হোস্ট হয়েছে কিনা নিশ্চিত করুন
  (http:// দিয়ে ইনস্টল অপশন আসে না, শুধু https:// এ কাজ করে)
